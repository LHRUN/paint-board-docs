# Select and edit

Select mode changes what is already on the board.

## Select

- Click any drawing, or drag on empty space to pull out a selection box.
- `Shift` + click another drawing to select more than one.
- `Cmd/Ctrl` + `A` selects everything.
- Clicking a row in the layer list also selects that object. Hidden objects are not selected.

Once something is selected, drag a handle on the box to scale or rotate it, or drag inside the box to move it.

## What you can change in the panel

The current selection shows these settings:

| Setting | What it does |
| --- | --- |
| Opacity | Sets how transparent the object is |
| Eraser | When this is off, Eraser mode skips the object |
| Lock | The object can no longer be moved, rotated, or scaled |
| Layer | Bring forward, send backward, bring to front, send to back |

`Cmd/Ctrl` + `]` and `Cmd/Ctrl` + `[` also change the stacking order of the selection.

Some settings appear only for certain objects:

- Pictures can take filters.
- Text can change font, style, and color.
- Brushes and shapes can change draw color and type.

## Layer list

The layer button on the bottom bar lists every object on the current board. From the list you can select an object, show or hide it, or drag it to change the stacking order.

## Copy, paste, and delete

| Action | How |
| --- | --- |
| Copy | The copy button on the bottom toolbar, or `Cmd/Ctrl` + `C` |
| Paste what you just copied | `Cmd/Ctrl` + `V` |
| Paste a picture from the system clipboard | `Cmd/Ctrl` + `B` |
| Duplicate in place | `Cmd/Ctrl` + `D` |
| Delete | The delete button on the bottom toolbar, or `Backspace` |

These edits can be undone and redone.  
Click the undo button, or press `Cmd/Ctrl` + `Z`.  
Click the redo button, or press `Cmd/Ctrl` + `Shift` + `Z`.  
On a touch screen, a two-finger double tap undoes and a three-finger double tap redoes.

## Alignment guides

Turn on **Alignment guides** in Board mode. While you drag objects, the guides help them line up with each other. The switch is described on [Board settings](/guide/canvas).
