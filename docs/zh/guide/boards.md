# 多画板

Paint Board 同一页面下支持多个画板，满足你丰富的创作需求。点击底部工具栏的画板按钮即可打开多画板列表进行切换和设置。

## 画板设置

- **新建画板** 会要求填写名称，并选择起点。可以选 **空白画板**，也可以选下面预设模版。
- 点击卡片即可打开那块画板。。
- **重命名** 使用同样的规则：去掉两端空格后的名称必须唯一。

当前画板会有标记。缩略图生成之后会出现在卡片上。还没有缩略图时，卡片会显示暂无缩略图。

### 删除

勾选一张或多张画板时，支持批量删除。

画板至少需要保留一个。如果全部被选中，当前画板会保留，其余被删除。

### 限制

- 新建到 20 块为止。已经超过这个数量的旧画板仍然可以打开，只是不能再新增。列表会提示已达到上限。
- 达到上限后，也不能再上传画板文件。上传方式见下面的「打开画板文件」。
- 画板卡片不能拖动排序。能拖动排序的是图层列表里的对象，以及背景层。

### 画板存在哪里

画板通过 IndexedDB 保存在当前浏览器里，不会上传到账号。清除这个网站的数据后，画板也会消失。换电脑或清理浏览器之前，先下载 JSON，或把多块画板打成一个 ZIP。

## 导入与导出

有两个地方可以导出：
+ 点击底部工具栏的保存按钮。
+ 在多画板列表选择多个画板可以批量下载。

### 保存 PNG

| 菜单项 | 结果 |
| --- | --- |
| 导出当前可视区域 | 一张你现在看到的范围的 PNG |
| 导出所有绘画内容 | 一张包含所有绘画内容的 PNG |
| 导出选中内容 | 当前选择内容的 PNG。有选中内容时才会出现这一项 |

PNG 真正下载前，预览里可以旋转、缩放、裁切，并选择是否带上背景。确认后再保存图片。

导出图片的单边不超过 16384 像素，总像素不超过 4096 × 4096 × 4。如果结果会更大，应用会提示图片太大，并建议缩小内容或降低缩放后再试。

从其他网站载入的图片也可能让导出失败。这时的提示会说明画布里可能有来自其他网站的图片。

### 保存画板数据

**导出当前画板数据** 会下载一个 `.json` 文件。文件名来自画板标题。不能出现在文件名里的字符会被换掉，过长的名字会被截短。

在画板列表里勾选多张卡片，再选择批量下载。应用会生成 `paint-board.zip`，里面是每块画板一个 JSON。如果两个标题会得到同一个文件名，会再加上一段短编号。窗口会显示整体进度。部分画板失败时，ZIP 里仍然会有成功的那些。如果一个都写不出来，则不会开始下载。

### 打开画板文件

画板列表里的 **上传** 接受画板 `.json`。有效文件需要有标题和画板数据。

这些情况会拒绝上传：

- 文件不是应用能识别的画板 JSON。
- 画板数量已经到达 20。

### 哪些不是画板工程

应用不会把 PSD、SVG 或 PDF 当作一块画板导入。  
JPEG 和 PNG 是放到画板上或用作背景的图片，不是完整备份。想再次打开同样的图层、文字和图形时，请使用 JSON。

### 使用提示

- 清理浏览器之前先导出 JSON。网站数据被清除后，IndexedDB 里的画板也会消失。
- 导出失败时，去掉跨站图片或降低缩放，再从保存菜单重试。
