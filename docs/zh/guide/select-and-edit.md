# 选择与编辑

选择模式用来改已经画在画板上的内容。

## 选中

- 点击任意一个绘画内容，或者在空白处拖动，拉出选择框。
- `Shift` + 点击新的绘画内容可以指定选择多个元素。
- `Cmd/Ctrl` + `A` 选中全部。
- 点击图层列表也可以选中绘画对象。隐藏的对象不会被选中。

选中后，可以点击矩形选择框的手柄进行缩放或者旋转，也可直接点击选择框内部拖动进行移动。

## 面板里能改什么

当前选中对象会出现这些设置：

| 设置 | 作用 |
| --- | --- |
| 透明度 | 透明度设置 |
| 橡皮擦 | 关掉之后，橡皮擦模式会跳过这个对象 |
| 锁定 | 对象不能再移动、旋转或缩放 |
| 图层 | 上移一层、下移一层、放到最前、放到最后 |

通过快捷键 `Cmd/Ctrl` + `]` 和 `Cmd/Ctrl` + `[` 也可以调整选中对象的叠放顺序。

有些设置只在特定对象上出现：

- 图片可以设置滤镜。
- 文字可以设置字体、样式和颜色。
- 画笔和图形可以设置绘画颜色和类型。

## 图层列表

底部的图层按钮会列出当前画板上的全部绘画对象。在这个列表里可以指定选择对象，显示或隐藏对象，也可以拖动某个绘画对象，改变图层顺序。

## 复制、粘贴和删除

| 操作 | 做法 |
| --- | --- |
| 复制 | 底部工具栏复制按钮，或 `Cmd/Ctrl` + `C` |
| 粘贴刚复制的对象 | `Cmd/Ctrl` + `V` |
| 粘贴系统剪贴板里的图片 | `Cmd/Ctrl` + `B` |
| 原位再复制一份 | `Cmd/Ctrl` + `D` |
| 删除 | 底部工具栏删除按钮，或 `Backspace` |

这些修改都可以通过撤销和重做返回。  
点击底部工具栏撤销按钮或者快捷键 `Cmd/Ctrl` + `Z` 进行撤销。  
点击底部工具栏重做按钮或者快捷键 `Cmd/Ctrl` + `Shift` + `Z` 进行重做。  
在触控屏上，双指双击撤销，三指双击重做。  

## 对齐辅助线

在画板模式里打开 **辅助线**。拖动对象时，辅助线会帮助它们互相贴齐。开关说明在 [画板设置](/zh/guide/canvas)。
