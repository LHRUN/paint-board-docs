# 快速开始

Paint Board 是一款完全开源的 Web 端创意画板。支持多种画笔、涂鸦图形、文字和图片，可以满足你的丰富创作需求。

预览地址：[songlh.top/paint-board](https://songlh.top/paint-board/)。  
Github 源码：[github.com/LHRUN/paint-board](https://github.com/LHRUN/paint-board)。  
如果感觉好用，欢迎点个 Star ✨，谢谢！

## 第一次打开

第一次打开时，页面会弹出预设模版。可以选中一张后点创建初步了解画板功能，也可以直接关掉窗口，从空白画板开始。

## 工具面板

页面主要的操作区都是在左侧的工具面板。分为以下四种模式，可自行展开收起：

| 模式 | 快捷键 | 用来做什么 |
| --- | --- | --- |
| 绘画 | `1` | 画笔和形状绘画 |
| 橡皮擦 | `2` | 随意擦除已绘画内容 |
| 选择 | `3` | 选择绘画内容进行缩放拖拽移动或者二次编辑 |
| 画板 | `4` | 画板配置 |

## 移动和缩放画面

无限画板，可随意拖拽移动以及缩放画面。

- 按住 `Space` 再拖动，可以平移。或者 `Cmd/Ctrl` 加方向键也可以平移
- 鼠标滚轮缩放。或者 `Cmd/Ctrl` 加 `+` 或 `-` 同样也可以缩放。
- 左下角的圆形指示会显示当前缩放比例，点击后会把缩放恢复到 100%。同样按快捷键 `Cmd/Ctrl` 加 `0` 也可把缩放恢复到 100%。
- 触控屏上，双指拖动平移，双指捏合缩放。双指双击撤销，三指双击重做。

## 底部工具栏

从左到右依次是：

1. 撤销，以及重做。
2. 复制当前选中内容。
3. 组合当前选中的多个内容。
4. 删除当前选中内容。
5. 添加文字。
6. 上传图片。
7. 清除画板。清除前会二次确认。
8. 保存画板。支持导出当前可视区域、全部绘画内容或选中内容的 PNG，也可以下载当前画板的 JSON 数据，用于多画板的导入导出。
9. 打开图层列表。
10. 打开画板列表。
11. 进入或退出全屏。

左下角的帮助按钮可以查看快捷键、功能简介，以及切换语言。  
目前支持语言：简体中文、繁体中文、English、日本語、한국어

## 一次最简单的绘画

1. 按 `1` 切换至绘画模式，选一种画笔。
2. 在空白处按下并拖动。
3. 按 `3` 切换至选择模式，拖动刚画的内容就可以移动它。
4. 需要 PNG 或 JSON 备份时，点击保存按钮。

画作保存在当前浏览器里。要换一台电脑继续画，先导出画板文件。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 选中全部 | `Cmd/Ctrl` + `A` |
| 加选 | `Shift` + 点击 |
| 复制 / 粘贴 | `Cmd/Ctrl` + `C`，然后 `V` |
| 粘贴系统剪贴板 | `Cmd/Ctrl` + `B` |
| 原位复制一份选中内容 | `Cmd/Ctrl` + `D` |
| 删除选中内容 | `Backspace` |
| 上移或下移图层 | `Cmd/Ctrl` + `]` 或 `[` |
| 撤销 / 重做 | `Cmd/Ctrl` + `Z`，以及 `Cmd/Ctrl` + `Shift` + `Z` |
